# Third-party components

Encore bundles these open-source audio libraries. Their dependencies and the Microsoft .NET / Windows Desktop runtime are included in the self-contained executable.

| Component | Version | License | Source |
| --- | --- | --- | --- |
| NAudio (Core, WASAPI, WinMM, ASIO, MIDI, WinForms) | 2.2.1 | MIT | https://github.com/naudio/NAudio |
| NVorbis | 0.10.4 | MIT | https://github.com/NVorbis/NVorbis |
| NLayer | 1.16.0 | MIT | https://github.com/naudio/NLayer |
| Microsoft .NET / Windows Desktop runtime | 8.0.31 | MIT and bundled third-party notices | https://github.com/dotnet/runtime, https://github.com/dotnet/wpf |

The audio libraries' original license texts and runtime notices accompany the release in `licenses/`. The bundled demo songs and artwork were created for this project and are covered by the project license. Imported user songs are not part of the distribution.
